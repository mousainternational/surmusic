Put the free DB-IP "IP to City Lite" file here to see visitors' cities in the admin panel.

1. Open https://db-ip.com/db/download/ip-to-city-lite
2. Download the CSV file (named like dbip-city-lite-2026-10.csv.gz). Do not unzip it.
3. Put it in this folder and start the site again (START-WINDOWS.bat). It is imported automatically.
